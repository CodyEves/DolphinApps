04Soak test

  1. The night before load-in, power the robot and leave it running enabled and disabled for time.
  2. Watch status LEDs and the Driver Station log for reboots or dropouts.
  3. Test any subsystem that uses remote sensors or closed loops on the new stack.

05Rules

  1. No software updates at the event unless the event requires one or a mentor approves. Team rule
