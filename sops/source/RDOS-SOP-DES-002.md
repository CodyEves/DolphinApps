## At a glance
1. **Rules:** read the bumper section (see Before you build)
2. **Wood:** cut to the frame (see Build)
3. **Hardware:** correct T-nuts and bolts (see Build)
4. **Cover:** fabric and numbers (see Build)
5. **Inspect:** check against the rules (see Inspection check)

## Before you build
1. Read the bumper rules in this season's game manual. They change. [Source: FIRST game manual]
2. Confirm the final frame perimeter and mounting points with the CAD Lead.
3. Order hardware early. Write the size on the order: our bumpers use **1/4-20 T-nuts**, not 10-32. [Team rule]

## Build
1. Cut the backing wood to the frame dimensions from CAD.
2. Install 1/4-20 T-nuts and test-fit every bolt before covering.
3. Add the cushion material specified in the manual.
4. Cover with fabric in both alliance colors (or a reversible set). Staple evenly and trim.
5. Add team numbers in the size and stroke the manual requires. We use TPU numbers [EDIT: confirm].
6. Mount on the robot only once the robot itself is legal on frame perimeter and height.

## Inspection check
- [ ] Dimensions and height zone match the manual
- [ ] Team numbers visible on every side, correct size
- [ ] Both colors available and in good repair
- [ ] Mounting is secure and quick to swap
- [ ] Spare bumper wood and fabric packed for the event
