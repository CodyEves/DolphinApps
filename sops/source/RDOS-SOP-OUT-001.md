1. **Gate 1:** decide (see Gate 1: Decide)
2. **Gate 2:** staff (see Gate 2: Staff)
3. **Gate 3:** prepare (see Gate 3: Prepare)
4. **Gate 4:** run (see Gate 4: Run)
5. **Gate 5:** record (see Gate 5: Record)

## Outreach gates
### Gate 1: Decide
1. Bring the invitation to mentors and officers. Check it doesn't clash with other events.
2. Reply to the host by the date promised.

### Gate 2: Staff
1. Create a channel named #outreach-event-name and a sign-up canvas.
2. Announce it. Members join the channel and add their name to an open position.
3. KEY: Every event needs an adult mentor and a student leader. If none signs up, ask in #mentors. [Team rule]

### Gate 3: Prepare
1. Collect host forms (waivers, ID requirements, security lists) by the host's deadline.
2. Test the demo robot (RDOS-SOP-OUT-002).
3. Pack using the outreach packing list.

### Gate 4: Run
1. Arrive on time in team clothing, ready to explain the team, FIRST and the robot.
2. Run demos safely: disable the robot before anyone steps into its area.
3. Take photos following RDOS-SOP-MEDIA-001.

### Gate 5: Record
1. Log outreach hours in [EDIT: outreach hours log].
2. Send photos to the media team and notes to the Impact Lead.
3. Thank the host.
