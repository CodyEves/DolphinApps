03Mentor sign-off

  1. ALL CAM, from any source, is checked by a mentor before the first cut. Team rule
  2. The mentor reviews the simulation and setup sheet with the programmer.
  3. Approved programs are marked how sign-off is recorded, e.g. in the training tool or the request thread.

04Records

  • Program file saved in CAM folder location with the part name and date.
  • Proven programs are marked "proven" so they can be rerun without a new dry run.
