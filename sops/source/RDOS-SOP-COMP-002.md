summary: A dedicated kit for taking down field elements, kept separate from pit tools so the pit can pack while the team helps with teardown.

## At a glance
1. **Check:** kit complete before load-in (see Kit contents)
2. **Keep separate:** never used for the robot (see Rules)
3. **Teardown:** kit goes to the field (see Using the kit)
4. **Return:** every tool back in (see Using the kit)

## Kit contents
The checklist is also on the bag tag.
- [ ] 15/16 in. wrenches (2), standard for truss systems
- [ ] 15/16 in. driver bits (2)
- [ ] Phillips driver bits
- [ ] Driver bits and extensions for field perimeter fasteners
- [ ] Snips for zip ties (4)
- [ ] [EDIT: other items]
- [ ] Carry case

Power drivers are not included. Bring them from the pit if needed.

## Rules
1. KEY: Don't remove tools from this kit for use during competition. [Team rule]
2. The kit may be used to help an event with field assembly.
3. Tell the Operations Lead before the event if anything is missing so it can be bought.

## Using the kit
1. The kit is ready at load-in on the first day and especially on the last day for teardown.
2. Logistics checks every tool back in at the end of teardown.
