## At a glance
1. **Gate 1:** set the decision date (see Gate 1: Set the decision date)
2. **Gate 2:** design the backup (see Gate 2: Design the backup)
3. **Gate 3:** go or no-go (see Gate 3: Go or no-go)
4. **Gate 4:** build and test (see Gate 4: Build and test)

## Plan B gates
### Gate 1: Set the decision date
1. When a new or rebuilt robot is planned for an event, mentors set a decision date about [EDIT: days] before the event. [Mentor]
2. Write down what "on track" means by that date (for example drives, intakes, scores).

### Gate 2: Design the backup
1. A small group designs the simplest robot that can still contribute: for example a drive base with a hopper, or a defense and feeding robot.
2. Use existing drive bases and stock parts. Cut from polycarbonate and plywood if it's faster.
3. Make the parts list and pre-cut what can be cut without committing.

### Gate 3: Go or no-go
1. On the decision date, compare the main robot to the "on track" list.
2. Go: the backup group builds. No-go: the backup parts are stored for spares.

### Gate 4: Build and test
1. Build the backup in as few sessions as possible; zip ties and simple mounts are fine.
2. Drive test, add a simple autonomous if possible, and pack spare materials.
